# Balanced OKRs

**Measure progress without losing sight of what matters.**

Balanced OKRs extends Objectives and Key Results with explicit guardrails and diagnostic measures to help teams recognize adverse tradeoffs, metric gaming, and delayed consequences.

This repository is being developed as two complementary publications:

- A short, shareable pamphlet introducing the approach.
- A more substantial, chaptered guide exploring design principles, examples, and implementation practices.

The documents are written in Markdown so they can be reviewed, improved, and published in multiple formats.

This is a proposed adaptation of OKRs, not a claim to be an established or officially endorsed OKR standard.
